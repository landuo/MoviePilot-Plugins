# 站点刷流-landuo

站点刷流-landuo V5 使用 Vue 模块联邦提供任务工作台。每项任务独立绑定一个站点和一个下载器，并拥有自己的调度周期、选种与删种规则、托管记录、统计和运行诊断。

全局设置支持限制所有任务合计的保种体积、同时下载任务数和总上传下载带宽；任务编辑器中的运行限额仍只约束当前任务。限额留空或设置为 `0` 表示不限制。

全局动态删种会汇总所有启用任务的做种体积。单值阈值（如 `100`）在达到 100 GB 后删到 100 GB；区间阈值（如 `50-100`）在达到 100 GB 后删到 50 GB。任务启用动态删种时，其已完成非 H&R 种子会参加全局兜底淘汰；未启用的任务只会在全局阈值触发后按自身删种条件处理。关闭全局模式时，没有独立动态删种阈值的参与任务会恢复为按条件删除。

任务可启用站点账号分享率控制：插件读取 MoviePilot 最新站点统计，当前分享率达到目标时等待，低于目标时自动恢复新增种子。启用控制但尚无可用统计数据时，任务会等待数据更新。

## 升级兼容

- V5 依赖 MoviePilot `v2.14.6+` 提供的 Vue 联邦宿主能力，旧版宿主会在安装和更新前拒绝该版本。
- 首次加载 V5 时，旧版 `brushsites` 会按站点拆分为独立任务。
- 从 V4 直接升级时，原有运行限额和全局动态删种会迁移到新的全局设置；已升级到 V5 的用户可在全局设置中重新设置合计限额。
- 旧版站点覆盖 JSON 会合并到对应任务中。
- 原有种子、归档和未托管数据会按站点迁移到任务命名空间。
- 已有的全局 `刷流` 标签继续识别；V5 新增任务唯一标签，避免多个任务互相接管。
- V5.0.2 会在插件启动、任务检查和任务删除后清理 qBittorrent 中不再被任何种子使用的 `刷流-*` 标签；仍绑定种子的标签不会被强制移除。
- V5.1.0 新增站点账号分享率目标控制，并限制运行诊断长列表在模块内部滚动。
- V5.1.1 修复 YemaPT 间接下载链接只返回 token、导致刷流任务无法获取种子 Hash 的问题。
- V5.1.2 会在最近的免费促销截止时间即时检查未完成下载，同时保留周期检查兜底，并修正跨时区到期判断。
- V5.2.0 恢复 V4 的全局动态删种，并适配 V5 的多任务、多下载器和任务级托管开关。
- V5.2.1 修复同一下载器共享种子的跨任务保护，并按任务记录实际删除原因。
- V5.2.2 将详情弹窗的滚动限制在右侧工作区，固定顶部标题栏和左侧任务栏，并移除重复失效的配置切换按钮。
- V5.2.4 合并上游 V5.2.3，并保留同站点同标题不同内容种子的定制排重逻辑。
- V5.2.3 兼容 qBittorrent 5.2.3，修复动态删种后的未使用标签清理报缺少 `hashes` 参数。
- V5.2.6 修复“删除促销过期的未完成下载”在促销截止时间缺失或格式不同时静默失效的问题。
- V5.2.7 促销截止时间缺失时改为直接读取种子详情页的促销信息补齐，站点选择器失效（例如 ubits）也能在促销结束时删除未完成下载。
- V5.2.8 详情页探测只依据当前种子自身的促销状态判定：有促销倒计时按点删除，站点明确声明“无优惠”才判定促销结束删除，状态未知时保持观察，避免把同页其他版本种子或标题里的“免费”字样误当成促销。
- V5.2.9 已拿到促销截止时间的种子会持续复核站点促销状态，站点提前结束促销时立即删除，不再等到原定截止时间。
- V5.2.11 获取新种子 Hash 后立即删除一次性随机标签；查询失败时同样清理，清理接口异常会记录警告但不影响加种结果。
- V5.2.12 在加种前核实当前种子的限时免费状态；提前 10 分钟清理未完成下载；详情页无法核实时先暂停，并修复其它版本促销误判和倒计时反复延后。

## 删除促销过期的未完成下载

任务启用「删除促销过期的未完成下载」（`del_no_free`）后，插件采取保守策略，避免优惠结束后仍让未完成种子下载：

1. **加种前**读取当前种子的详情页，必须同时看到免费标记与可解析的促销截止时间，且截止时间距现在超过 10 分钟；页面失效、优惠已经结束、仅有倒计时却无法确认免费时跳过该候选，不启动下载。列表页的免费标记不能单独作为加种依据。
2. **下载中**调度器每 15 分钟复核当前种子详情页；启用此功能的任务计划检查间隔固定为 15 分钟，包括其它常规删种条件。已知截止时间的未完成种子仍会在截止前 10 分钟触发独立清理任务并删除，普通周期检查也会兜底。
3. 站点明确显示「无优惠」、倒计时已经结束或优惠提前撤销时立即停止并删除未完成下载；详情页无法核实、Cookie 失效、没有截止时间时先暂停下载，不能继续带风险刷流。若下载器暂停接口失败，则尝试删除受影响种子；删除也失败会在运行记录中报错。
4. 因无法确认而暂停的种子不会被插件自动恢复；请先确认站点优惠有效，再手动恢复下载。可选的「促销最长时长」仍可将长期无法确认的未完成种子兜底删除。

截止时间可来自列表页的绝对时间、`freedate_diff` 或详情页；相对倒计时会固定到首次加入时刻，不会每轮检查重新顺延。支持显式时区和原有站点时区偏移；详情页解析会排除 UBits `kothercopy` 区块中的其它版本种子。

| 详情页情况 | 判定 |
| --- | --- |
| 当前种子同时显示免费标记与有效截止时间，且超过 10 分钟 | 允许新下载或继续现有下载 |
| 截止时间在 10 分钟内、已过期、当前种子明确无优惠 | 删除未完成下载 |
| 只有免费图标或只有倒计时，或页面无法确认状态 | 不新增下载；已下载的未完成种子先暂停 |
| 页面不是种子详情页（登录页、RSS、错误页等） | 按无法确认处理，并提示检查 Cookie |

H&R、动态删种、代理删种和删除排除标签不会绕过这一安全检查。促销安全删除也不会在删种前再向 Tracker 主动汇报。

### 促销提前结束的处理

站点仍可能无预警地提前撤销优惠；插件只能在下一次详情页复核时发现，无法控制插件停机、下载器断连或站点计费延迟。因此 10 分钟提前量不是对任何站点零计费的绝对保证。若站点没有可靠的详情页优惠截止时间，开启本功能会阻止新种子下载或暂停旧种子，以安全优先。

> **站点促销选择器**：MoviePilot 内置站点配置（`resources.v2/user.sites.v2.bin`）中部分 NexusPHP 站点的 `freedate` 选择器使用了 `font[color] > span[title]`。当站点在 `<font>` 与 `<span>` 之间插入 `<b>`（例如 ubits.club 的 `剩余时间：` 行）时，该选择器匹配不到任何行，`freedate` 恒为 `None`。V5.2.7 起插件会用详情页探测自动补上这个数据；若希望列表页阶段就拿到截止时间，也可以把选择器改为后代写法：
>
> ```json
> "freedate": {
>   "selector": "td:nth-child(2) > table.torrentname > tr > td:nth-child(1) > font[color] span[title]",
>   "attribute": "title"
> }
> ```
>
> 实测 ubits.club 列表页：原选择器命中 0/100 行，改为后代写法后命中 51/51 个免费种子。RSS 不包含促销信息，因此启用「使用 RSS」的任务仍依赖详情页核验。

## 前端入口

插件构建产物暴露以下联邦组件：

| 组件 | 用途 |
| --- | --- |
| `AppPage` | 主界面侧栏中的完整刷流工作台 |
| `Page` | 插件详情弹窗 |
| `Config` | 插件配置弹窗 |
| `Dashboard` | 仪表板任务概览 |

侧栏入口由插件的 `get_sidebar_nav()` 注册，可在工作台全局设置中关闭。

## 插件 API

所有接口均使用宿主 Bearer 认证，基础路径为 `/api/v1/plugin/BrushFlowLanduo`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/status` | 获取全局状态、任务摘要与可选站点下载器 |
| `POST` | `/settings` | 更新插件与侧栏入口开关 |
| `POST` | `/tasks` | 创建任务 |
| `GET` / `PUT` / `DELETE` | `/tasks/{task_id}` | 查询、更新或删除任务 |
| `POST` | `/tasks/{task_id}/state` | 启用或暂停任务 |
| `POST` | `/tasks/{task_id}/run` | 立即执行刷流刷新 |
| `POST` | `/tasks/{task_id}/check` | 立即执行种子检查 |
| `POST` | `/tasks/{task_id}/clear` | 清除当前任务的独立数据 |

## 构建

在本目录安装依赖后执行 `yarn build`，产物生成到 `dist/assets`，由插件后端的 Vue 渲染模式加载。
